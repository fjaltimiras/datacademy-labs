# Reglas del cotizador de despacho (inventadas)

1. Zona Santiago: $4.000. Zona Regiones: $6.500. Incluye hasta 5 kg.
2. Sobre 5 kg, $700 por cada kilo extra o fracción. Ejemplo: 5,5 kg paga un kilo extra.
3. En Santiago, si la compra es de $60.000 o más, el despacho es gratis (0). En Regiones no.
4. Si falta un dato, el peso es cero o negativo, o la zona no existe: ERROR y no se calcula.
5. No guarda ni envía datos.
